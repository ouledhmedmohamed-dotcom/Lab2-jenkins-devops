# Lab2 - chaine CI Jenkins

## Contexte
Formation DevOps - Linqiny
Module: Pratique II - Integration Continue

## Objectif
Mettre en place une chaine CI avec Jenkins et Git : installation de Jenkins, creation d'un exemple de Java Maven, Publication sur GitHub, et build automatique via Jenkins.

## Etape realisees
1. Creation d'un VM CentOS7 dediee a Jenkins
2. Installation de Jenkins et Java (openjdk 8)
3. Installation de Maven
4. Creation d'un exemple Java simple (App.java + AppTest.java) avec Maven
5. Build reussi avec mvn clean package
6. Publication du code sur GitHub
7. Test Poll SCM automatique - Mohamed

## Technologies utilisees
- CentOS7
- Jenkins
- Java 8 (openjdk)
- Maven
- Git / GitHub
